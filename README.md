# RoadVision AI — AI-Powered Helmet & Number Plate Detection System

RoadVision AI is a modern, high-performance computer vision web application and analytics dashboard designed for motorcycle traffic safety monitoring, helmet compliance inspection, and license plate localization using a fine-tuned **YOLO11n** object detection model.

## 3. Features Implemented

### A. Image Detection Workspace
- **Drag-and-Drop Ingestion:** Accepts JPEG, JPG, PNG, and WEBP formats with configurable file size limits (default: 15MB).
- **Validation & Safe Revocation:** Strict client-side validation; automatic revocation of temporary object URLs to prevent browser memory leaks.
- **Inference Lifecycle:** Asynchronous requests with abort controller cancellation, progress spinners, and duplicate submission locks.
- **Interactive Canvas Overlay:** Pixel-accurate rendering of bounding boxes aligned to image coordinates with responsive scaling. Hovering over table rows highlights the corresponding box with outer glow. Click-to-select support.
- **Multi-View Modes:**
  1. *Interactive Canvas:* Dynamic SVG/Canvas overlay with toggleable labels, confidence scores, and class filtering.
  2. *Backend Render:* Direct visualization of the annotated image generated by the FastAPI model.
  3. *Original:* Clean unprocessed input photo.
  4. *Side-by-Side:* Comparison view of original input versus detection results.
- **Export & Download:** One-click download of high-resolution annotated images directly from the backend or rendered from the canvas.

### B. Overview Dashboard
- Session-level metrics: total images analyzed, total objects detected, helmet detections, safety violations, and license plates.
- Safety compliance rate gauge ($Helmets / (Helmets + No\_Helmets)$).
- Recharts bar chart showing class distribution across the session.
- Live system status card reflecting the backend connection state and loaded model checkpoint.
- Recent analyses list with click-to-reopen navigation.

### C. Detection Results Table
- Clean table displaying Detection #, Class Badge, Confidence formatted as percentage (e.g., `94.2%`), and Bounding Box coordinates `[x1, y1, x2, y2]`.
- One-click copy for bounding box coordinates.
- Sortable by confidence (asc/desc), class name, or detection index.
- Search filter for narrowing down specific detected items.

### D. Session History
- Session-scoped audit log tracking filename, file size, timestamp, inference latency, and class breakdown chips.
- Export entire session log as JSON.
- Re-inspect any past session item in the workspace with one click.
- Clear transparency disclaimer: no permanent server storage without consent.

### E. Model Information
- Technical documentation of the YOLO11n Nano architecture (~2.6M parameters, letterbox 640×640 px).
- Verified dataset and training methodology (`Helmet-&-Number-Plate-Detection-2-1` and `Bike-Number-Plate-1`, 50 epochs, `close_mosaic=20`, `mosaic=1.0`).
- Responsible AI notice clarifying that the tool is an operator decision-support system, not a punitive autonomous enforcement engine.

### F. Settings & Demo Mode
- Configurable backend API base URL with a live "Test Connection" tool.
- Sliders for Confidence threshold (`conf`, default `0.25`) and IoU threshold (`iou`, default `0.45`).
- Image inference resolution selector (`320`, `640`, `768`, `1024`).
- **Explicit Demo Mode:** Can be toggled on to demonstrate the complete UI with simulated predictions even when the Python backend is offline, clearly marked with a high-visibility badge.

### G. Future-Ready Video Analysis
- Transparent beta preview of the continuous video stream pipeline (OpenCV frame sampling, ByteTrack multi-object tracking, and violation aggregation). No fake progress bars.

## 4. Quick Start Guide

### Prerequisites
- Node.js 18+ (tested on v22.20)
- Python 3.10+ (tested on 3.11 with `ultralytics`, `fastapi`, `uvicorn`, `opencv-python`)

### Option A: One-Click Launch (Windows)
Double-click `start_app.bat` or run:
```powershell
.\start_app.bat
```

### Option B: Manual Launch

#### 1. Start the FastAPI Backend
```powershell
python -m uvicorn backend.main:app --port 8000 --host 127.0.0.1 --reload
```
- API Base: `http://127.0.0.1:8000`
- Interactive Swagger Docs: `http://127.0.0.1:8000/docs`

#### 2. Start the React Frontend
In a separate terminal:
```powershell
npm run dev
```
- Frontend UI: `http://localhost:5173`

#### 3. Production Build
To test the production build:
```powershell
npm run build
npm run preview
```

## 5. API Endpoints Contract

### Health Check
`GET /health`
```json
{
  "status": "ok",
  "model_loaded": true,
  "model_name": "YOLO11n (Helmet & Number Plate)",
  "device": "cpu",
  "classes": ["helmet", "no_helmet", "number_plate", "pillion", "rider"]
}
```

### Image Inference
`POST /predict?conf=0.25&iou=0.45&imgsz=640`
- Payload: `multipart/form-data` with field `file`
- Expected Response:
```json
{
  "success": true,
  "filename": "traffic_01.jpg",
  "inference_time_ms": 38.4,
  "image_width": 1280,
  "image_height": 720,

      "bbox": [240.5, 110.2, 380.0, 260.4]

  "counts": {
    "helmet": 1,
    "no_helmet": 0,
```
